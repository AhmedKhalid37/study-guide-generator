# Worked examples

The sum is simple: 2 + 3 = 5.

Multiplication: 3 × 4 = 12.

Division gives a clean result: 10 / 4 = 2.5.

The square root: sqrt(16) = 4.

The exponential of zero: exp(0) = 1.

A rounded fraction: 1 / 3 ≈ 0.333.

Logistic output: exp(1.43) / (1 + exp(1.43)) ≈ 0.806.

Inline math wrapper holds too: $2 + 2 = 4$.
